# 🎮 GameStore

A full-stack web application designed for managing and cataloging video games. Built with a modern **ASP.NET Core Minimal APIs** backend and a reactive **React (TypeScript)** frontend powered by **Vite**.

## 📖 Overview

**GameStore** provides a streamlined management dashboard where administrators can browse, create, update, and remove video games from the catalog. The project demonstrates end-to-end full-stack integration, implementing standard RESTful CRUD patterns, decoupled database migrations with Entity Framework Core, and clean client-server communication using Vite Proxy.

### ✨ Key Features
- **Catalog Management:** Full CRUD capabilities (Create, Read, Update, Delete) for games and categories.
- **RESTful Endpoints:** Minimal APIs architecture in .NET with explicit DTO mapping and data validation.
- **Modern UI:** Built with React 19, TypeScript, and custom styling for a smooth management experience.
- **Seamless Local Proxy:** Configured Vite dev proxy to route client requests to the backend without CORS overhead.
